Scan filenames and XMP without changing them

Sidecar Ledger reads image filenames and adjacent XMP. It does not change source files.

local shell
$ cargo install --git https://github.com/B-Divyesh/sf-photo-edit-ledger.git --locked
$ sidecar-ledger scan ~/Pictures/Archive \
    --from lightroom --to immich --json

# Exit 0: portable · 2: review · 1: input error
