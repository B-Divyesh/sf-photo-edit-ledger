Privacy, in plain terms

The command-line program runs on your computer. It has no telemetry or network client. It does not upload image bytes, filenames, XMP values, or reports.

The website

The sample demo uses shipped data in your browser. It does not inspect local files.

Optional Pro license

If you restore Pro access, the site stores your token and its check time in browser storage. The token goes only to the Sociobot billing API when a check is due. It is not sent with photo metadata.

Your control

You can remove the stored token in the Pro panel or clear this site’s browser storage. The command-line program leaves your photographs untouched.

Contact

For privacy questions, open an issue in the public repository (external).
